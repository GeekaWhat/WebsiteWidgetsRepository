Corsair RM750e White Connector Reference

PCIe (6+2 pin)

Connector Type
PCIe 6+2-pin
Build Usage
Not used for the main RTX 5070 configuration.
Notes
Used by GPUs that require standard 8-pin PCIe power (for example some Radeon alternatives).

12V-2x6

Connector Type
12V-2x6 (ATX 3.1 / PCIe 5.1)
Typical Output
Up to 600W (GPU dependent)
Build Usage
This is the active GPU power connector for the RTX 5070

ATX 24-pin

Connector Type
ATX 24-pin
Quantity Included
1
Primary Use
Motherboard power (ASUS ROG Strix B860-G Gaming WiFi)
Notes
Required for all standard desktop builds.

CPU EPS (4+4)

Connector Type
4+4-pin EPS 12V
Quantity Included
2 cables
Primary Use
CPU power for Intel Core Ultra 7 265K
Notes
Use the required EPS connection on the motherboard; second EPS can be used for additional headroom if needed.

SATA (15-pin)

SATA storage, fan/ARGB hubs, accessories

Optional (primary storage is M.2 NVMe; may be used for hubs or accessories)

Peripheral (Molex 4-pin)
