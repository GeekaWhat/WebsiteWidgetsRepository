Pros and Cons

Pros

  • Strong multi frame generation performance
  • Similar power draw to the previous generation
  • Competitive pricing for a new 80-class launch

Cons

  • Multi frame generation adds latency
  • Game support for multi frame generation is still limited
  • Raster performance uplift versus the RTX 4080 SUPER is modest

Bottom Line

The RTX 5080 is a sensible pick for a brand-new high-end gaming PC, especially if you want access to NVIDIA's latest DLSS 4 and multi frame generation features. It is still the better card than the RTX 4080 SUPER at the same launch price, but the upgrade case is much less convincing for anyone already on an RTX 4080-class GPU because native gains are comparatively small.
