Motherboard Specifications

  • Model

    MSI MPG X870E CARBON WiFi

  • Chipset / Socket

    AMD X870E / Socket AM5

  • Form Factor

    ATX (243.84 x 304.8mm)

  • CPU Support

    AMD Ryzen 9000 / 8000 / 7000 Series desktop processors

  • Memory Support

    4 x DDR5 DIMM, up to 256GB

    AMD EXPO memory overclocking support

  • VRM Design

    18+2+1 Duet Rail Power System

  • Graphics Card Compatibility (1 Slot)

    PCI_E1 PCIe 5.0 x16 primary graphics slot for modern high-end GPUs

    PCI_E3: PCIe 4.0 x4

    M.2_3 PCIe 4.0 x4 (22110/2280)
    M.2_4 PCIe 4.0 x4 (2260/2280)

    4 x SATA 6Gb/s

  • Networking

    Realtek 8126 5G LAN
    Realtek 8125 2.5G LAN
    Wi-Fi 7 + Bluetooth 5.4

  • Rear I/O

    2 x USB4 Type-C (40Gbps)
    5 x USB 10Gbps Type-A
    4 x USB 5Gbps Type-A
    1 x HDMI 2.1
    1 x 5G LAN + 1 x 2.5G LAN
    Wi-Fi antenna connectors + optical S/PDIF

  • Front I/O Headers

    1 x USB 20Gbps Type-C front header with 27W PD

    2 x USB 2.0 headers (4 ports)
    Front audio, RGB, ARGB, TPM, and fan headers
